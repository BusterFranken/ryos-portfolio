# Read me first 👋

Welcome! This portfolio is built as a little retro operating system — and **every window is one of my projects.**

Poke around: open the desktop icons, browse the  menu, and try switching the whole OS between **Mac OS X** and **Windows** in *Control Panels → Appearance*.

## Where to start

- **Live projects** run right here inside their windows — look for the ones that load a real site.
- **Gallery** collects screenshots from things that don't live on the web.
- **Videos** has a few of my talks.
- Some windows open the real project in a new tab — look for the **↗** buttons.

## Easter eggs

There are a few hidden things. One window will even try to *escape the OS* entirely. Have a dig.

## Reach me

Open **Contacts** for my email, LinkedIn, GitHub, and YouTube — the "email" button there will start a message to me. Always up for a good conversation.
