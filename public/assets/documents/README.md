## README

A quick orientation. This portfolio is a small retro operating system, and every window is one of my projects.

Poke around: open the desktop icons, browse the top menus, and switch the whole OS between Mac OS X and Windows in Control Panels → Appearance.

### Where to start

- Live project windows load a real, deployed site right inside the window.
- Gallery collects screenshots of things that don't live on the web.
- Videos has a few of my talks.
- Some windows open the real project in a new tab.

### Easter eggs

A few things are hidden. One window even tries to escape the OS. Have a dig.
